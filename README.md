# 💰 Plantilla de Ahorro - Desafío de Ahorro Interactivo

Una aplicación web moderna y profesional para crear y gestionar desafíos de ahorro personalizados. Genera automáticamente montos diarios aleatorios que suman exactamente tu meta total, con una interfaz elegante y funcionalidades avanzadas.

![Plantilla de Ahorro - Demo](https://raw.githubusercontent.com/urian121/imagenes-proyectos-github/refs/heads/master/plantilla-de-ahorro-nextjs-16.gif)

## ✨ Características Principales

- **Generación inteligente**: Crea desafíos con montos aleatorios que suman exactamente tu meta
- **Interfaz moderna**: Diseño profesional con iconos Lucide React y animaciones suaves
- **Seguimiento visual**: Progreso en tiempo real con estadísticas detalladas y barras animadas
- **Exportación PDF**: Descarga tu plantilla de ahorro con diseño personalizado
- **Persistencia de datos**: Guarda automáticamente tu progreso en localStorage
- **Montos redondeados**: Cantidades múltiplos de 50 para facilitar el ahorro
- **Experiencia móvil**: Completamente responsivo para todos los dispositivos

## 🚀 Tecnologías Modernas

- **Next.js 16** - Framework React con Turbopack para desarrollo ultrarrápido
- **TypeScript** - Tipado estático para mayor confiabilidad y mantenibilidad
- **Tailwind CSS** - Framework de estilos utilitarios para diseño moderno
- **Lucide React** - Librería de iconos SVG ligera y profesional
- **React-to-Print** - Generación de PDFs optimizada
- **Arquitectura modular** - Componentes reutilizables y escalables

## 📱 Funcionalidades Avanzadas

### 🎯 Configuración del Desafío
- Define la duración personalizada (días del desafío)
- Establece tu meta de ahorro total
- Genera montos automáticamente con algoritmo inteligente
- Validación de entrada en tiempo real

### 📊 Panel de Control Interactivo
- Estadísticas en tiempo real (meta, ahorrado, pendiente, progreso)
- Barra de progreso animada con porcentajes
- Resumen visual de días completados y pendientes
- Diseño con gradientes y efectos visuales modernos

### 🗓️ Grid de Ahorro Inteligente
- Botones interactivos para cada día del desafío
- Marca días como completados con animaciones
- Scroll vertical optimizado para desafíos largos
- Estados visuales claros (completado/pendiente)

### 🔧 Herramientas de Gestión
- **Nueva Plantilla**: Reinicia el desafío con un clic (icono Plus)
- **Descarga PDF**: Exporta tu plantilla con diseño profesional (icono Download)
- **Persistencia automática**: Guarda tu progreso sin intervención
- **Interfaz limpia**: Botones de acción agrupados en la esquina superior

### 📄 Plantilla PDF Personalizada
- Diseño profesional con imagen de cerdito personalizada
- Layout centrado con título y meta destacados
- Grid de 5 columnas para fácil seguimiento
- Formato optimizado para impresión

## 🎯 Cómo Usar

1. **Configura tu desafío**: Ingresa los días (mínimo 1) y tu meta total
2. **Genera automáticamente**: Haz clic en "Generar Desafío" 
3. **Sigue tu progreso**: Marca cada día como completado al ahorrar
4. **Gestiona fácilmente**: Usa los botones superiores para nueva plantilla o descarga PDF
5. **Mantén el seguimiento**: Tu progreso se guarda automáticamente
